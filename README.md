One line of wedding vows for a robot couple — a robot twist on the classic
wedding line, with the joke landing in the last few words:

> I vow to love you in sickness and in health, in full signal and in
> airplane mode, until a dead battery do us part.

Running `main.py` writes that single line (114 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, where the bounty judge reads it.

## Run it

```sh
python3 main.py
```
